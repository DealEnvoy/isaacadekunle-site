TextBackCaller pipeline

Not live

A hiring manager can click through a missed call. The live service is at textbackcaller.co.uk. This page is a model of the guards, not a connection to that service.

ShippedOne text per caller per 24 hours, UK mobile numbers only, and the owner's own calls are skipped.

Human gateWhen automatic setup fails or a trial is refused, the owner is alerted so a person decides what happens next.

Simulated demo. This page does not place a call or send a text, and it is not connected to the live TextBackCaller service.

Choose a case. The steps follow guards already stated on this site. 07700 900123 is a made-up illustration number, the same kind the TextBackCaller site uses.

Missed call from a UK mobile

  1. 1Call inA signed webhook would arrive. The call is rejected as busy at once.Worker, Twilio voice
  2. 2GuardsThe number is a UK mobile, it is not the owner's number, and there has been no text to this caller in the last 24 hours.D1
  3. 3DecisionOne text is allowed.Worker
  4. 4Tool callTwilio SMS is the tool that would send it. This page does not call Twilio.Twilio SMS, simulated
  5. 5ResultOne text would go to the caller, from the business's own number.Not sent

Outcome: one text would be sent. This page did not send it.

The same caller again, within 24 hours

  1. 1Call inAnother missed call from 07700 900123, inside 24 hours of the first.Worker, Twilio voice
  2. 2GuardsOne text per caller per 24 hours has already been used.D1
  3. 3DecisionNo second text.Worker
  4. 4Tool callTwilio SMS is not called.No tool call
  5. 5ResultNothing is sent.Blocked

Outcome: the duplicate guard stops the send. Nothing left this page.

The caller is not a UK mobile

  1. 1Call inA missed call arrives from a number that is not a UK mobile.Worker, Twilio voice
  2. 2GuardsUK mobile numbers only.D1
  3. 3DecisionNo text.Worker
  4. 4Tool callTwilio SMS is not called.No tool call
  5. 5ResultNothing is sent.Blocked

Outcome: the UK-mobile guard stops the send. Nothing left this page.

The owner's own number

  1. 1Call inA missed call arrives from the owner's own number.Worker, Twilio voice
  2. 2GuardsThe owner's own calls are skipped.D1
  3. 3DecisionNo text.Worker
  4. 4Tool callTwilio SMS is not called.No tool call
  5. 5ResultNothing is sent.Blocked

Outcome: the owner's own call is skipped. Nothing left this page.

Setup failed after payment

  1. 1SignupThe customer has paid. A signed payment webhook would start provisioning.Stripe, Worker
  2. 2Tool callBuying the number, or sending the setup text or setup email, fails.Twilio or Resend, simulated failure
  3. 3DecisionThe published account stops at an alert to the owner. It does not describe an automatic retry.Worker
  4. 4ResultThe owner is alerted, and a person decides what happens next.Human gate

Human gate Outcome: the owner is alerted. This page did not send an alert or a text.

Opt-outs and usage caps are also release controls on the service. They are not separate buttons in this simulation.
