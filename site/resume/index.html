  • Drew & Crew Ltd. The company site, listing 9 ventures.
  • Agent CRS. A NEAR testnet vault for agent spending, built with AI coding agents for NEAR Hackathon 2026. The board is local, not hosted.

Specified, not built

  • airworthiness-mcp. A pre-registered study. Nothing has been built or run. No live demo, no video, and no trial result.

Public repositories

  • agent-crs. Policy vault on NEAR testnet. The agent holds a function call key, not a full access key. The board is started locally with npm run dev. It is not hosted.
  • crs-ai-agents. CRS Pilot 0, a small self-registered advisory evaluation. This is where the 16 of 16 detection line lives. False alarms are reported separately. Not the Agent CRS vault, and not a certification tool.
  • airworthiness-mcp. A pre-registered study. Nothing built or run. No results.
  • PitchReach-Case-Study. Dated audit notes. The application source stays private.
  • approve-before-pay. An agent prepares a PayPal order. Nothing is captured until a person approves that version. Separate from Agent CRS.
  • multi-agent-enquiry-desk. A reference demo of a supervised agent desk for a fictional lettings office. A person approves before any outcome is recorded. The repository says it has no client deployment, no users and no production traffic.
