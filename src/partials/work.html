airworthiness-mcp

Pre-registered study

This is a pre-registered study, not a working product. Nothing has been built or run. There is no live demo, no video, and no trial result.

Challenge

A person preparing a release decision can miss an open defect, a life limit, an overdue task, an airworthiness directive, or a page that is not in the pack. The repository frames the tool as a reading aid, not as the decision.

Solution

{{claim:aw-purpose}} {{claim:aw-rules}}

The planned default is a local command line program, with an MCP server for a client on the same machine. The records in the plan are synthetic.

Impact

{{claim:aw-status}} {{claim:aw-prereg}}

There is no pass rate. The 16 of 16 detection line belongs to crs-ai-agents, not to this study.

Stack

Specified as Python, a deterministic rules engine, and an optional local IBM Granite model that stays off until an operator switches it on. The default mode is specified with no network and no API key.

What Isaac owned

The repository says he designed the method: separate architect, implementer and reviewer roles, reviewers never the builder, and deterministic checks before he accepts a result. AI models are named as the build and review tools. There is no software release yet.

The same README states more than 15 years in aircraft maintenance. That is the method behind the design. This site does not claim a Part-66 licence or a certifying role.
